# Trivia

## Rules

1. "I'm always right". The host is always right, even if they're wrong. Scores won't be adjusted if the host happens to have a question with an inaccurate or incomplete answer.
2. "Don't use your phone". We're here to have fun and maybe learn something, not just to win. Cheating is not fun. Don't cheat.
3. "Don't shout out… Answers!". Players must write their answers down. Your answers are a team secret. Don't ruin the game by shouting answers to questions.

## Format

20 Questions
1 Tie Breaker/Guess the number

## Writing Questions

    1 Women's health/anatomy question
    1 Astrology question
    1 Tarot card question. Comprehensive Tarot Card info can be found at https://tarostarot.com/tarot-card-meanings

Other question inspiration:
* Pride flags
* Queer flagging
* Celebrities that came out this year
* Sapphic history made this year
* This day/week/month in history
* This day/week/month in women's sports
